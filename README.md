# anime spammer
this is a fun app

What anime spammer does is open a little window with a riddle. Every 10 secondes, an anime girl image appears. Every time you close the anime girl image, a new one appears 0.09 seconds faster. It also plays some annoying sounds and videos. If you try to close the app without answering the riddle, it will re-open automatically.

#features
6000 anime girl images

15 sound effects

a video

a few websites it opens
